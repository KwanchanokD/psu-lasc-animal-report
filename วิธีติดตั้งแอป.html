วิธีติดตั้งเป็นแอป — ระบบรายงานการปฏิบัติต่อสัตว์ทดลองของนักวิจัย

ติดตั้งลงคอมพิวเตอร์และมือถือได้เหมือนแอปทั่วไป · ศูนย์สัตว์ทดลอง ม.อ. (PSU:LASC)

ระบบนี้เป็นแอปแบบไหน

เป็น PWA (Progressive Web App) — ติดตั้งลงเครื่องได้เหมือนแอปทั่วไป มีไอคอนของตัวเอง เปิดเป็นหน้าต่างแยกไม่มีแถบเบราว์เซอร์ ใช้งานออฟไลน์ได้ และอัปเดตอัตโนมัติเมื่อออนไลน์

วิธีติดตั้งเหมาะกับเข้าสู่ระบบ/ซิงก์คลาวด์
ก. ติดตั้งจากเว็บ (PWA)ทุกเครื่อง ทั้งคอมพิวเตอร์ มือถือ แท็บเล็ต — แนะนำ ได้
ข. เปิดจากไฟล์ในเครื่องคอมพิวเตอร์ที่ยังไม่ได้เผยแพร่ระบบขึ้นเว็บ ไม่ได้ (เก็บข้อมูลในเครื่อง)
ข้อจำกัดของเบราว์เซอร์ — การเข้าสู่ระบบและซิงก์ข้อมูลกับศูนย์สัตว์ทดลอง ทำได้เฉพาะเมื่อเปิดผ่าน https:// เท่านั้น ถ้าเปิดจากไฟล์ (file://) ระบบจะทำงานแบบเก็บข้อมูลในเครื่องและแจ้งเตือนให้ทราบ

ก. ติดตั้งจากเว็บ (แนะนำ)

ขั้นที่ 1 — นำระบบขึ้นโฮสต์ (เจ้าหน้าที่ทำครั้งเดียว)

อัปโหลด ทุกไฟล์ในโฟลเดอร์นี้ ขึ้นที่ใดที่หนึ่งที่เปิดผ่าน https:// ได้ เช่น GitHub Pages (แบบเดียวกับระบบอื่นของศูนย์ฯ) หรือเว็บเซิร์ฟเวอร์ของหน่วยงาน

ไฟล์จำเป็นไหม
index.htmlจำเป็น — ตัวระบบ
manifest.webmanifestจำเป็น — ทำให้ติดตั้งเป็นแอปได้
sw.jsจำเป็น — ใช้งานออฟไลน์ + อัปเดตอัตโนมัติ
icon-192.png icon-512.pngจำเป็น — ไอคอนแอป
screenshot-wide.png screenshot-narrow.pngแนะนำ — รูปตัวอย่างในหน้าต่างติดตั้ง
วิธีใช้งาน.html วิธีติดตั้งแอป.htmlแนะนำ — คู่มือ
ไฟล์ .md .cmd .ps1 firebase-rules.json ไม่จำเป็นต้องอัปโหลด — เป็นเอกสารและเครื่องมือสำหรับเจ้าหน้าที่

ขั้นที่ 2 — ติดตั้งลงเครื่อง

อุปกรณ์วิธีทำ
🖥 Windows / macOS
(Chrome, Edge)		 เปิด URL ของระบบ → กดปุ่ม 「⬇ ติดตั้งแอป」 ที่มุมขวาบนของระบบ หรือกดไอคอน ⊕ ท้ายแถบที่อยู่เว็บ หรือเมนู ⋮ → Install / ติดตั้งแอป → จะได้ไอคอนบนเดสก์ท็อปและในเมนู Start
📱 Android (Chrome) เปิด URL → กดปุ่ม 「⬇ ติดตั้งแอป」 ในระบบ หรือเมนู ⋮ → เพิ่มไปยังหน้าจอหลัก
📱 iPhone / iPad (Safari) เปิด URL → ปุ่มแชร์ ⬆ → เลื่อนหา เพิ่มไปยังหน้าจอโฮม (Add to Home Screen) → เพิ่ม
iOS ไม่มีปุ่มติดตั้งอัตโนมัติ ต้องทำผ่านปุ่มแชร์เท่านั้น
ทางลัดในไอคอนแอป — เมื่อติดตั้งแล้ว คลิกขวาที่ไอคอนแอป (Windows/Android) จะมีเมนูลัดไปยัง รายงานใหม่ · ประวัติการรายงาน · สรุปผล ได้ทันที

ข. เปิดเป็นแอปจากไฟล์ในเครื่อง (Windows)

ถ้ายังไม่ได้นำระบบขึ้นเว็บ ก็เปิดให้ทำงานเหมือนแอปบนเดสก์ท็อปได้ โดยใช้ไฟล์ที่เตรียมไว้ในโฟลเดอร์นี้ — เปิดเป็นหน้าต่างแยก ไม่มีแถบเบราว์เซอร์

  1. ดับเบิลคลิก เปิดเป็นแอป.cmd — ระบบจะเปิดในหน้าต่างแอปทันที (ใช้ Chrome หรือ Edge ที่มีอยู่ในเครื่อง)
  2. ถ้าต้องการไอคอนถาวร ให้ดับเบิลคลิก สร้างทางลัดบนเดสก์ท็อป.cmd หนึ่งครั้ง → จะได้ไอคอน 「ระบบรายงานการปฏิบัติต่อสัตว์ทดลอง PSU-LASC」 บนเดสก์ท็อป
  3. ต่อไปเปิดใช้งานได้จากไอคอนนั้นเลย
ถ้าเผยแพร่ระบบขึ้นเว็บแล้ว — เปิดไฟล์ app-url.txt ใส่ URL ของระบบไว้บรรทัดเดียว (ไม่ต้องมี # นำหน้า) แล้วบันทึก ตัวเปิดแอปจะเปิด URL นั้นแทนไฟล์ในเครื่อง ทำให้เข้าสู่ระบบและซิงก์ข้อมูลได้ จากนั้นสร้างทางลัดใหม่อีกครั้ง
ถ้า Windows ขึ้นเตือนว่าบล็อกไฟล์ที่ดาวน์โหลดมา ให้คลิกขวาที่ไฟล์ .cmd → Properties → ติ๊ก Unblock → OK แล้วเปิดใหม่อีกครั้ง
ยังไม่ใช่โปรแกรมติดตั้ง .exe — ระบบนี้เป็นเว็บแอปที่รันด้วยเบราว์เซอร์ที่มีอยู่ในเครื่อง จึงไม่ต้องติดตั้งโปรแกรมเพิ่ม ไม่ต้องขอสิทธิ์ผู้ดูแลเครื่อง และอัปเดตได้ทันทีโดยไม่ต้องลงใหม่ทุกเครื่อง หากหน่วยงานต้องการไฟล์ .exe จริง ๆ ต้องนำไปแพ็กด้วย Electron หรือ Tauri เพิ่มเติม

การอัปเดตแอป

  • ติดตั้งจากเว็บ — เมื่อเจ้าหน้าที่อัปโหลดไฟล์ใหม่ ระบบจะตรวจพบเองและขึ้นแถบ 「🔄 มีแอปเวอร์ชันใหม่พร้อมใช้งาน」 ด้านบน กด อัปเดตทันที ก็ได้เวอร์ชันล่าสุด (ตรวจให้อัตโนมัติทุกครั้งที่กลับมาที่แอป และทุก 30 นาที)
  • เปิดจากไฟล์ในเครื่อง — คัดลอกไฟล์ index.html ตัวใหม่ทับของเดิม
ข้อมูลรายงานไม่หายเมื่ออัปเดต — ถ้าเข้าสู่ระบบอยู่ ข้อมูลอยู่บนฐานข้อมูลกลาง ถ้าไม่ได้เข้าสู่ระบบ ข้อมูลยังอยู่ในเบราว์เซอร์ของเครื่องนั้น (ควรกด「⬇ สำรองข้อมูล (JSON)」ไว้เป็นระยะ)

ถอนการติดตั้ง

Windowsเปิดแอป → เมนู ⋮ มุมขวาบนของหน้าต่างแอป → ถอนการติดตั้ง หรือ Settings → Apps → ค้นหาชื่อแอป → Uninstall
Androidกดค้างที่ไอคอนแอป → ถอนการติดตั้ง
iPhone / iPadกดค้างที่ไอคอน → ลบแอป
ทางลัดบนเดสก์ท็อปลบไอคอนทางลัดทิ้งได้เลย ไม่กระทบข้อมูล
การถอนการติดตั้งจะลบข้อมูลที่เก็บไว้ในเบราว์เซอร์ของเครื่องนั้นด้วย — ถ้ายังไม่ได้เข้าสู่ระบบเพื่อซิงก์ ให้กด 「⬇ สำรองข้อมูล (JSON)」 เก็บไว้ก่อน
