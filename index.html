Animal Procedure Reporting System — ศูนย์สัตว์ทดลอง มหาวิทยาลัยสงขลานครินทร์ (PSU:LASC)

👩‍🔬 โหมดนักวิจัย
🔄 มีแอปเวอร์ชันใหม่พร้อมใช้งาน

1️⃣ เลือกเลขที่โครงการวิจัยที่ต้องการรายงาน

⚠️ ยังไม่มีโครงการในระบบ — เลขที่โครงการวิจัยจะถูกดึงเข้าระบบโดยเจ้าหน้าที่ (แอดมิน) จากระบบจริยธรรมการวิจัยในสัตว์ (animalethic.research.psu.ac.th) กรุณาติดต่อเจ้าหน้าที่ศูนย์สัตว์ทดลองเพื่อนำเข้าข้อมูลโครงการของท่าน

2️⃣ ข้อมูลสัตว์ทดลองที่ต้องการรายงาน

ℹ️ ระบบเติมค่าจากข้อมูลโครงการให้อัตโนมัติ — แก้ไขได้หากรุ่นที่รายงานนี้ต่างจากที่ระบุในโครงการ

3️⃣ เลือกรายการที่ต้องการรายงาน

⚖️ รายละเอียดการุณยฆาต (Euthanasia)



🚚 รายละเอียดการเคลื่อนย้ายสัตว์ทดลองออกนอกสถานที่ (Off-site transport)



🕊️ รายละเอียดสัตว์ตายระหว่างการศึกษา (Died during the study)



4️⃣ ข้อมูลการดำเนินการและผู้รายงาน



💡 หลังบันทึกแล้ว สามารถเปิดแท็บ 「📚 ประวัติการรายงาน」 เพื่อดู แก้ไข หรือกด 「📄 พิมพ์ / PDF」 เพื่อออกแบบฟอร์มรายงานสำหรับแนบเสนอคณะกรรมการฯ

4️⃣ ผู้แจ้ง (ให้ทีมสัตวแพทย์ติดต่อกลับ)

เมื่อกดส่ง ระบบจะบันทึกเรื่องเข้ากล่องรับแจ้งของทีมสัตวแพทย์ และส่งอีเมลแจ้งเตือนทันที (ถ้าศูนย์ฯ ยังไม่ได้ตั้งค่าส่งอีเมลอัตโนมัติ ระบบจะเปิดร่างอีเมลให้กดส่ง)

📋 รายการแจ้งเหตุของฉัน

👥 อนุมัตินักวิจัยที่ลงทะเบียน

🔐 ต้องเข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่ (uid อยู่ใต้ allowed) จึงจะเห็นรายชื่อผู้ลงทะเบียนและอนุมัติได้
นักวิจัยลงทะเบียนเองจากปุ่ม「🔑 เข้าสู่ระบบ」→「📝 ลงทะเบียน」— อนุมัติแล้วรายงานที่เขาบันทึกไว้ในเครื่องจะส่งขึ้นระบบกลางอัตโนมัติ และถ้าต่อ n8n ไว้ ระบบจะแจ้งผลการอนุมัติทางอีเมลให้

🩺 ทีมสัตวแพทย์ที่รับแจ้งเหตุ (LINE + อีเมล)

🔐 ต้องเข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่ จึงจะจัดการรายชื่อผู้รับแจ้งได้
＋ เพิ่มสัตวแพทย์ / กลุ่ม LINE ที่รับแจ้ง

📲 เพิ่มสัตวแพทย์ใหม่ทาง LINE ได้ทันที — ให้สัตวแพทย์เพิ่มเพื่อน LINE Official Account ของศูนย์ฯ แล้วพิมพ์ ลงทะเบียน ชื่อ-สกุล (หรือเชิญบัญชีเข้ากลุ่มสัตวแพทย์แล้วพิมพ์ ลงทะเบียน ในกลุ่ม) คำขอจะขึ้นด้านล่าง กด「➕ เพิ่มเป็นผู้รับแจ้ง」→ บันทึก → เริ่มรับแจ้งเตือนได้ทันที · เพิ่มเฉพาะอีเมลก็ได้โดยไม่ต้องใช้ LINE

🔖 วิธีที่ใช้ได้จริงเสมอ — ปุ่ม Bookmarklet「ดึงข้อมูล animalethic」
ระบบจริยธรรมฯ ต้องล็อกอินและไม่เปิด CORS ให้เว็บอื่นอ่านข้อมูล เบราว์เซอร์จึงบล็อกการดึงตรงจากหน้านี้ วิธีที่ทำงานได้คือให้สคริปต์ทำงานบนหน้าเว็บของระบบจริยธรรมฯ เอง ขณะที่ท่านล็อกอินอยู่:
  1. ลากปุ่มด้านล่างไปวางบน แถบบุ๊กมาร์ก ของเบราว์เซอร์ (หรือกด「📋 คัดลอกโค้ด」แล้วสร้างบุ๊กมาร์กใหม่วางเป็น URL)
  2. เปิดระบบจริยธรรมฯ แล้วล็อกอิน ไปที่หน้ารายการโครงการ (/home) หรือหน้า protocol ที่ต้องการ
  3. กดบุ๊กมาร์ก「ดึงข้อมูล animalethic」— สคริปต์จะเก็บข้อมูลหน้านั้นและไล่ดึงรายละเอียดโครงการที่มีลิงก์ในหน้า แล้วบันทึกเป็นไฟล์ animalethic-export.json
  4. กลับมาที่ระบบนี้ กด「⬆ นำเข้าไฟล์จาก Bookmarklet」เลือกไฟล์ดังกล่าว → ตรวจทานรายการ → นำเข้าทะเบียน
🔖 ดึงข้อมูล animalethic ← ลากปุ่มสีเขียวไปวางบนแถบบุ๊กมาร์ก
